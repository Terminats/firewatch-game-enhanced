Firewatch Enhanced 1.2.0
========================

Compatibility
-------------
This package targets the 64-bit GOG release of Firewatch.

Installation
------------
1. Open the game directory containing Firewatch.exe.
2. Extract all files from this archive directly into that directory.
3. Start the game.

The package includes BepInEx 5.4.23.5 x64. On the first launch, BepInEx creates
its configuration and log directories automatically.

Features
--------
- High frame rate movement fix
- Optional FPS counter in General (off by default)
- Optional unlimited dialogue time in General (off by default)
- Subtitle Size slider in General (75%-200%, default 100%)
- Field of View slider in Graphics (30-110, default 55)
- Mouse Acceleration checkbox in Controls
- Includes Ignore Pads option which is set by default, this fixes issue with controllers causing automatic rotation of character.
- New Game (Skip Intro) button
- Faster save loading and asset-streaming improvements
- Reduced player interaction checks above 60 FPS

Noclip for testing
------------------
Press F8 while playing to toggle noclip.

    W/A/S/D       move horizontally
    Space         move up
    Left Ctrl     move down
    Left Shift    move faster

Uninstall only the patch
------------------------
Delete:

    BepInEx\plugins\FirewatchHighFpsFix.dll

Removing BepInEx completely
---------------------------
Only do this if no other installed mods use BepInEx. Remove:

    BepInEx
    winhttp.dll
    doorstop_config.ini
    .doorstop_version
